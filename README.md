# IK’s Charms & True Sparkle

Parent house landing page for **KayzCharmzz** and **True Sparkle** — a Black-owned, woman-led, family-owned studio in Cleveland, Ohio.

- Live: [https://www.ikscharmsandtwosparkles.com](https://www.ikscharmsandtwosparkles.com)
- KayzCharmzz handmade gifts: [https://www.kayzcharmzz.com](https://www.kayzcharmzz.com)
- True Sparkle original diamond painting kits: [https://www.truesparkles.com](https://www.truesparkles.com)

Contact: **Lana Moss** — [lana@ikscharmsandtwosparkles.com](mailto:lana@ikscharmsandtwosparkles.com) · 216-309-0331
